# v4.1.0 — Trustworthy Runs

**Date:** 2026-11-09

## Summary

The operator can trust a green Healthchecks ping. A run that degrades says
so, uses fewer Claude calls, and keeps secrets in their lane.

## Issues Resolved

- [#143](https://github.com/unibrain1/TheSommelier/issues/143) — security: Claude gets only its own key, credentials leave argv, menu output is checked, and the site sends security headers.
- [#142](https://github.com/unibrain1/TheSommelier/issues/142) — fix: The success ping counts and lists warnings, the fail ping names the step, and a failed digest send pings.
- [#108](https://github.com/unibrain1/TheSommelier/issues/108) — feat: A sync keeps the tasting note of a week with the same wine and marks, so Claude writes only new notes.
- [#145](https://github.com/unibrain1/TheSommelier/issues/145) — chore: v4.0.0 review cleanup. `send_digest.sh` reads `.env` unless both SMTP secrets are set, as `fetch.sh` does.
- [#148](https://github.com/unibrain1/TheSommelier/issues/148) — feat: The site footer and `/version.json` show the image version: `X.Y.Z`, `edge-<sha>` or `dev`.

## Deployment

_To do: add the steps as issues finish._

- #143: Remove `OP_SERVICE_ACCOUNT_TOKEN` from `.env`. The sync in the container now warns when it is set.
- #143: A line break in `SYNC_SCHEDULE` or `DIGEST_SEND_SCHEDULE` now stops the container start. So does a cron expression that is not valid, or more than one expression in `DIGEST_SEND_SCHEDULE`. Check both values before the update.
- #143: Set `USERNAME` and `PASSWORD` as plain text. curl now URL-encodes them. A password that you encoded by hand, such as `p%26ss` for `p&ss`, no longer logs in.
- #143: With an `http://` value in `GOOGLE_CALENDAR_ICS_URL` or `HEALTHCHECK_URL`, each sync logs a warning, because the URL holds a secret. Change the value to `https://`.
- #143: A control character in `USERNAME` or `PASSWORD` now stops the run. A CRLF `.env` can give one: save it with LF line ends.
- #142: The success ping body now has a `Warnings: N` line and lists each warning. A failed or stale digest send now sends a fail ping to `HEALTHCHECK_URL`. The next sync success ping sets the check up again.
- #142: The scheduled sync and the first sync run through the new `sync.sh`. Pull the new image. No setting changes.
- #143: The site now sends a Content-Security-Policy. It allows only the site itself and Google Fonts, so a script, style or image that you add from another host is blocked.
