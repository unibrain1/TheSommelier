# v4.2.0: Operator Visibility

**Date:** 2026-11-25 (draft)

## Summary

The operator can see on the site which features are on and how each one did on the last run. This release also fixes edge cases that hid a degraded run or a failed digest.

## Security

- The site escapes each plan and menu value it writes as HTML, so a wine name or note cannot run a script (#158).

## Fixes

- The ping warns when the community notes feed is not RSS, and the sync keeps a corrupt community notes cache (#155).
- A meal with no usable enrichment, such as a meal out, goes to Claude again two days later, not on each sync (#149).
- The sync writes the digest files atomically, so a send at the same minute cannot read half a file (#156).
- A digest that the SMTP server refuses for some recipients now sends a fail ping with the refused count. The optional `HEALTHCHECK_DIGEST_URL` gives the digest its own check (#154).
