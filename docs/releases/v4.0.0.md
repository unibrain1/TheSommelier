# v4.0.0 — Standalone Container

**Date:** 2026-11-02 (draft)

## Summary

A home-lab operator can run The Sommelier from a published image with only
env variables and volumes. The container needs no repo checkout, no
1Password, and no SSH access to Home Assistant.
